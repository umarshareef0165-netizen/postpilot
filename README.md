# PostPilot

A brief becomes a full day of social posts — drafted by an agent, edited by you, scheduled through Buffer.

Built for **Buffer Commit 2026**. Live app: see GitHub Pages link.

- OAuth 2.0 Authorization Code + PKCE (public client, no secret)
- Drafting engine: hooks, questions, tips, mini-stories and CTAs rotated around your brief
- Privacy: tokens live only in your browser (localStorage). No PostPilot server exists.
